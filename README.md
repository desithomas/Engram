# demo-day


Project BowBow is the in-development codename for this demo day project. 

Project BowBow is a student focused academic planning application that is designed to help users organize their assignments, deadlines, review sessions, and course materials in one place. The application allows students to record assignment details, estimated the actual required work time, track their energy levels and progress, search their assignments, view reminders, nd selected related files such as PDFs, Python files, JavaScript files, notes and much more. The current front end prototype uses HTML, CSS, JavaScript and localStorage (browser local storage) with future plans for a backend, authentication, OCR, calendar integration, spaced repetition, active recall, and personalized workload recommendations.

If you use this product while it is still in development, please expect limited functionality and bugs as development continues. Bugs will be squashed!
